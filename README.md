# Sistem Pendaftaran Ekstrakurikuler Sekolah (HTML & Bootstrap)

Proyek sederhana ini menyajikan daftar Ekstrakurikuler Sekolah menggunakan HTML5 dan kerangka kerja CSS Bootstrap. Dibuat sebagai latihan dasar dalam pengembangan antarmuka pengguna (UI) dan desain responsif.

## 🛠️ Teknologi yang Digunakan

* **HTML5:** Struktur konten utama.
* **Bootstrap 5.:** Kerangka kerja untuk desain responsif dan komponen UI.

## ✨ Fitur Utama

* Menampilkan daftar kegiatan dengan deskripsi dan ikon.
* Desain responsif, tampilan baik di desktop maupun *mobile*.
